# Managed instruction projection

`bazarlyk.agentic.view.HostAgenticView` reads an opened layer and verified inventory.
The host resolver composes the canonical role and managed guidance with its own
native profile and authorization. The defaults contain Ordubashy, global worker
and learning applier; role definitions and native implementations are not editable
through agentic authoring. Catalogue selection, discovery and manifest metadata
never grant tools, credentials or plugin authority.

Each role receives the complete `user-preferences/preferences` skill from
`user-preferences/SKILL.md`. Relevant eligible plugin guidance is discoverable.
The existing bootstrap hooks and revision checks refresh the managed projection
and relevant catalogue at the next normal prompt or resume, without restarting
a session, waking a paused agent or injecting changes mid-turn. Native managed
skills use the existing projection. Discovering a custom plugin does not inject
or read every plugin body; agents locate and read relevant procedural entries. A delayed refresh
remains pending instead of returning stale instructions. A successful save does not establish refresh or delivery, publication or inbox
delivery. A delivery receipt records delivery, not model compliance; timings under particular test conditions are not
an arbitrary-load guarantee.

Managed skill refresh checks revisions and file integrity. Native orientation
drift (`native_guidance_changed`), foreign edits or incompatible projection drift
may require explicit preparation. See [host integration](AGENTIC-HOST-INTEGRATION.md)
for management and the separate authored/runtime roots. The API write boundary is
not an OS sandbox. Email guidance is under
`plugins/imported-email-management/guidance/email/`, with no second active seed.
