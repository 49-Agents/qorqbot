# Host documentation references

This repository can be checked out alone or as the `biz-dashboard` submodule of `qorqut-code`. Host paths below are relative to the code repository. Read the host at the matching Git pin.

The host's `docs/v1.2/OPERATING_GUIDE.md` is the entry point for operating the dashboard with the host. Installation is described in the host's `docs/INSTALLATION.md`; documentation here does not authorize merge, deployment or adoption.

## Service

`qorqut-code/app/bazarlyk/service/README.md`: host composition and the origin the dashboard is served from.

## Tables

`qorqut-code/docs/TABLES.md`: exact table revision history, separate from general operational snapshots.

## Signoffs

`qorqut-code/docs/SIGNOFF-INPUT-NOTIFICATIONS.md`: Signoff behavior and notifications.

## Parent Tasks

`qorqut-code/docs/v1.2/PARENT_TASKS_HOST.md`: work groups are ordinary parent Tasks. Old Story UI descriptions in historical release notes are not current functionality.

## Relationships

`qorqut-code/docs/v1.2/CONTEXT_COMPOSITION.md`: published shared Context. Operational relationships are separate; their engine implementation is the Operations engine's `qorqut_operations/relationships/` package.
