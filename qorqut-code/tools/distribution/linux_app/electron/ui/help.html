How Qorqbot works

Version

Opening and quitting

Open the appStarts Qorqbot's local server on this computer and shows the dashboard in this window. Opening it again shows the window that is already running.
Close the windowHides it to the system tray and Qorqbot keeps running; click the tray icon and choose Show Qorqbot to bring it back. If your desktop shows no tray icons, closing the window quits Qorqbot instead.
Quit (Ctrl+Q)Stops the local server, then quits. Also in the tray menu. Open the app again to continue where you left off.
Server menuShows whether the server is running, and can stop, start or restart it, open logs, or show the install folder. The tray menu has the same start, stop and restart.
View › Open in Browser (Ctrl+Shift+B)Opens the same dashboard in your web browser while the app is running.

The app itselfThe AppImage file, or the installed qorqbot package, only carries the installer package. Replacing or deleting it does not touch your data.

First launch

The first launch unpacks Qorqbot into the folder above. Everything it needs to run is inside the app, so nothing is downloaded or installed. It takes a few seconds, and so do later launches.

Claude Code and Codex are downloaded from Settings in Qorqbot, where you also sign in.

Applications menu

The .deb package puts Qorqbot in your applications menu when you install it. An AppImage is a single file, so the first launch asks once whether to add it. You can change your mind later with File › Add to Applications Menu or Remove from Applications Menu. If you move the AppImage file, open it once from its new place and the menu entry follows it.

Updates

When you open a newer Qorqbot app, it offers to update the installed copy. Your records stay in place. Running agents are closed first and start again when you next message them. If one cannot be closed, the update stops and leaves the installed version unchanged. If you chose Terminals under Settings › Agents, close the agents' terminals first: the update does not start while they run.

The AppImage does not start

An AppImage must be allowed to run: open the file's Properties and tick Allow executing file as program, or run chmod +x on it. Most systems also need FUSE 2 for AppImages (sudo apt install libfuse2t64 on Ubuntu 24.04, libfuse2 on older releases). The .deb package needs neither.

On Ubuntu 23.10 and newer the AppImage runs without Chromium's extra browser sandbox, because the system blocks the namespaces it needs. The .deb package keeps the sandbox on. Help › About Qorqbot shows which applies to you.

Removing Qorqbot

Quit Qorqbot, then remove the app: for an AppImage, choose File › Remove from Applications Menu first if you added it, then delete the AppImage file; for the package, run sudo apt remove qorqbot. Then delete the install folder ~/Qorqbot, which holds the folder above and the app's log. Deleting it deletes your Qorqbot records; back it up first if you want to keep them.
