Getting started

From the first launch to your first conversation with Ordubashy

How it fits together

Qorqbot does not run an AI model itself. Each agent is a coding CLI that you have installed and signed in to, running inside that agent's own terminal on this Macthis computer. Qorqbot gives the agent its instructions and tools, and the dashboard's chat sends your messages to that running session.

No session running means no chat. When an agent is offline, its chat says how to start it.

1. Install an agent CLI once

Every agent, Ordubashy included, runs on either CLI. Install one or both, then run it once in Terminala terminal and sign in:

Claude Codeclaude
OpenAI Codexcodex

You can mix them: start one agent with Claude Code and another with Codex.

2. Sign in to Qorqbot

The first time the dashboard opens, enter your email. Qorqbot sends you a code; type it in and say whether you use Qorqbot personally or for work. You do this once on this Macthis computer.

Qorqbot's servers learn only your email and that Qorqbot is in use, never your conversations, files or what your agents do.

3. Follow the walkthrough

It starts by itself after you sign in. It first asks once to trust Qorqbot's own agent folders. Allow it, and Claude Code and Codex open straight into the session without asking. Your other projects are not changed, and you can turn this off in Settings. If you don't allow it, Claude asks whether to trust the folder (press the down arrow, then Return on "Yes, I trust this folder") and Codex asks you to review its hooks.

Then you start Ordubashy in his own terminal: type claude or codex and press Return, whichever you are signed in to. He connects to the chat by himself. The tour then shows you around the workspace, projects, signoffs and Settings.

4. Say hello

The walkthrough ends in Ordubashy's chat. Type hi, help me get set up and send it. He asks a few quick questions about you, keeps the answers on this Macthis computer, then connects the tools you want him to use, such as the websites you sign in to through his browser.

Starting him again

Point at the mark at the top left of the dashboard. Its menu lists your agents, then Walkthrough, Terminal and Settings. Choose Ordubashy, click >_ above the chat to open his own terminal, and type claude or codex. Do this after every restart.

A session started in Terminal.appanother terminal window is not his session and the chat will not connect to it.

The walkthrough again

Skipped or finished, you can take it again, whole or one chapter: choose Walkthrough in that menu or in Settings, or Help › Show Walkthrough.

Use it in your browser

Choose Help › Install Terminal Command once. Then qorqbot in any Terminalterminal window opens the same dashboard in your browser, starting Qorqbot first if it is not running. qorqbot stop and qorqbot status work from any folder.

The app and the browser share one server. Quitting the app leaves a server started from Terminala terminal running.
