Getting started

From the first launch to your first conversation with Ordubashy

How it fits together

Qorqbot does not run an AI model itself. Each agent runs on Claude Code or Codex, which you sign in to with your own account. Qorqbot starts the agent on this Mac when you message it and gives it its instructions and tools. You talk to every agent in the dashboard's chat; there is no terminal to open.

An agent that has been idle for a while goes to sleep and starts again by itself the next time it has something to do.

1. Connect Claude Code or Codex once

Every agent, Ordubashy included, runs on either one. In Settings, download the one you use and sign in to it in your browser:

Claude CodeAnthropic account
OpenAI CodexChatGPT or OpenAI account

You can mix them: choose the client, model and effort of each agent in Settings.

2. Sign in to Qorqbot

The first time the dashboard opens, enter your email. Qorqbot sends you a code; type it in and say whether you use Qorqbot personally or for work. You do this once on this Mac.

Qorqbot's servers learn only your email and that Qorqbot is in use, never your conversations, files or what your agents do.

3. Follow the walkthrough

It starts by itself after you sign in. It shows you around the workspace, projects, signoffs and Settings, and ends in Ordubashy's chat. Sending your first message there starts him.

4. Say hello

The walkthrough ends in Ordubashy's chat. Type hi, help me get set up and send it. He asks a few quick questions about you, keeps the answers on this Mac, then connects the tools you want him to use, such as the websites you sign in to through his browser.

Starting him again

Point at the mark at the top left of the dashboard. Its menu lists your agents, then Walkthrough and Settings. Choose Ordubashy and send a message: he starts by himself, after every restart too. End session above the chat turns an agent off until you message it again.

The walkthrough again

Skipped or finished, you can take it again, whole or one chapter: choose Walkthrough in that menu or in Settings, or Help › Show Walkthrough.

Use it in your browser

Choose Help › Install Terminal Command once. Then qorqbot in any Terminal window opens the same dashboard in your browser, starting Qorqbot first if it is not running. qorqbot stop and qorqbot status work from any folder.

The app and the browser share one server. Quitting the app leaves a server started from Terminal running.
