Getting started

Talk to your first agent in four steps

How it fits together

Qorqbot does not run an AI model itself. Each agent is a coding CLI that you have installed and signed in to, running inside that agent's own terminal on this Mac. Qorqbot gives the agent its instructions and tools, and the dashboard's chat sends your messages to that running session.

No session running means no chat. When an agent is offline, its chat offers a Start button.

1. Install an agent CLI once

Every agent, Ordubashy included, runs on either CLI. Install one or both, then run it once in Terminal and sign in:

Claude Codeclaude
OpenAI Codexcodex

You can mix them: start one agent with Claude Code and another with Codex.

2. Open Ordubashy

In the dashboard, go to Global › Agents and select Ordubashy, your lead agent. Its chat opens.

3. Start him in his terminal

Click >_ above the chat to open Ordubashy's own terminal. Type claude or codex and press Return, whichever you are signed in to. He connects to the chat by himself. This is how you start him every time.

The walkthrough first asks once to trust Qorqbot's own agent folders. Allow it, and Claude Code and Codex open straight into the session without asking. Your other projects are not changed, and you can turn this off in Settings. If you don't allow it, Claude asks whether to trust the folder (press the down arrow, then Return on "Yes, I trust this folder") and Codex asks you to review its hooks.

The chat also has a Start Ordubashy button that types the command for you. A session started in Terminal.app is not his session and the chat will not connect to it.

4. Say hello

The status shows Connecting… for a moment, then the message box unlocks. Messages you send go into Ordubashy's running session and his replies appear in the chat.

If the session ends, the chat goes offline. Start him again in his terminal.

The walkthrough

The dashboard offers a walkthrough the first time it opens. It does steps 2 to 4 with you, then tours the workspace, projects and signoffs chapter by chapter. Skipped or finished, you can always take it again: click the ? button at the bottom left of the dashboard, or choose Help › Show Walkthrough.

Use it in your browser

Choose Help › Install Terminal Command once. Then qorqbot in any Terminal window opens the same dashboard in your browser, starting Qorqbot first if it is not running. qorqbot stop and qorqbot status work from any folder.

The app and the browser share one server. Quitting the app leaves a server started from Terminal running.
