Getting started

Talk to your first agent in four steps

How it fits together

Qorqbot does not run an AI model itself. Each agent is a coding CLI that you have installed and signed in to, running inside that agent's own terminal on this Mac. Qorqbot gives the agent its instructions and tools, and the dashboard's chat sends your messages to that running session.

No session running in the agent's own terminal means no chat. That is what "Not available to send" means.

1. Install an agent CLI once

Every agent, Ordubashy included, runs on either CLI. Install one or both, then run it once in Terminal and sign in:

Claude Codeclaude
OpenAI Codexcodex

You can mix them: start one agent with Claude Code and another with Codex.

2. Open the agent

In the dashboard, go to Global › Agents and select Ordubashy. Its chat opens. At the top are two buttons: the speech bubble shows Chat, and >_ shows the agent's own Terminal.

3. Start it in its own terminal

Click >_, type claude or codex and press Return. The chat names both while the agent is offline, its usual one first.

The first time, the CLI asks whether you trust the agent's folder. Choose Yes, I trust this folder (in Claude Code the highlighted answer is "No, exit", so press the down arrow first). Qorqbot prepared that folder and its tool permissions.

Start it in that terminal, not elsewhere. A session started in Terminal.app or another window is not that agent's session, even in the same folder, and the chat will not connect to it.

Background helpers Ordubashy hands work to run on the same CLI you started Ordubashy with.

4. Chat

Switch back with the speech bubble. The status shows Connecting… for a moment, then the message box unlocks. Messages you send there go into the same session that is running in the terminal, and its replies appear in the chat. You can switch between Chat and Terminal at any time.

If the CLI exits (you typed /exit or closed it), the chat goes offline again. Repeat step 3 to start a new session.

The walkthrough

The dashboard offers a walkthrough the first time it opens. It does steps 2 to 4 with you, then tours the workspace, projects and signoffs chapter by chapter. Skipped or finished, you can always take it again: click the ? button at the bottom left of the dashboard, or choose Help › Show Walkthrough.

Use it in your browser

Choose Help › Install Terminal Command once. Then qorqbot in any Terminal window opens the same dashboard in your browser, starting Qorqbot first if it is not running. qorqbot stop and qorqbot status work from any folder.

The app and the browser share one server. Quitting the app leaves a server started from Terminal running.
