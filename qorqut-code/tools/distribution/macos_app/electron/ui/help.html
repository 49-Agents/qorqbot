First launch

The first launch unpacks Qorqbot into the folder above and prepares its Python environment from the files inside the app (no downloads). It takes about a minute. Later launches take a few seconds.

Qorqbot uses programs you install yourself: Python 3.12, git and tmux. With Homebrew, run brew install python@3.12 git tmux in Terminal. Agent terminals use your own Codex or Claude Code installation.

Qorqbot uses Python 3.12, git and tmux. The Ubuntu package installs them with it. If one is missing, run sudo apt install python3.12 python3.12-venv git tmux in a terminal. Agent terminals use your own Codex or Claude Code installation.

Updates

When you open a newer Qorqbot app, it offers to update the installed copy. Your records stay in place. Close agent terminals first; the update refuses while they run and leaves the installed version unchanged.

"Qorqbot cannot be opened" on another Mac

This build is not notarized by Apple, so a downloaded copy is blocked the first time. Try to open it once, then choose System Settings › Privacy & Security › Open Anyway. After that it opens normally.

Removing Qorqbot

Quit Qorqbot, delete the app, then delete the install folder above. Deleting the folder deletes your Qorqbot records; back it up first if you want to keep them. Programs you installed with Homebrew stay installed.

Quit Qorqbot, then remove the app with sudo apt remove qorqbot. This leaves the ~/Qorqbot folder and its records in place. Deleting that folder deletes your Qorqbot records; back it up first if you want to keep them. Programs you installed with apt stay installed.
