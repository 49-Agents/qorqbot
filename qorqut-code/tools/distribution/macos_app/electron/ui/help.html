How Qorqbot works

Version

Opening and quitting

Open the appStarts Qorqbot's local server on this Mac and shows the dashboard in this window.
Close the windowHides it. Qorqbot keeps running; click the Dock icon to bring it back.
Quit (⌘Q)Stops the local server, then quits. Open the app again to continue where you left off.
Server menuShows whether the server is running, and can stop, start or restart it, open logs, or show the install folder.
View › Open in BrowserOpens the same dashboard in your web browser while the app is running.

Where things live

First launch

The first launch unpacks Qorqbot into the folder above. Everything it needs to run is inside the app, so nothing is downloaded or installed. It takes a few seconds, and so do later launches.

Claude Code and Codex are downloaded from Settings in Qorqbot, where you also sign in.

Updates

When you open a newer Qorqbot app, it offers to update the installed copy. Your records stay in place. Running agents are closed first and start again when you next message them. If one cannot be closed, the update stops and leaves the installed version unchanged.

"Qorqbot cannot be opened" on another Mac

This build is not notarized by Apple, so a downloaded copy is blocked the first time. Try to open it once, then choose System Settings › Privacy & Security › Open Anyway. After that it opens normally.

Removing Qorqbot

Quit Qorqbot, delete the app, then delete the install folder above. Deleting the folder deletes your Qorqbot records; back it up first if you want to keep them.
