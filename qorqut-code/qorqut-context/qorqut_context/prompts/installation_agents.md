## The installation's own agents

The installation's own AI agents are not entities of the Context. Never create
or update a node for one of them, and never add a relationship or note whose
only content is that an agent did, sent, checked or handled something; who
submitted or performed the work is already recorded on the event. When a source
says something lasting about a real person, organization, project, product or
account, file that fact on that subject without the agent.
