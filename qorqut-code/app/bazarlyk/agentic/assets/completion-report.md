Every completion report starts with the actual outcome: Done / Blocked / Needs you. Done means the requested outcome is verified; Blocked names the unfinished outcome and dependency; Needs you names the specific owner decision or action required. State what actually happened first, then any remaining work, responsible person and next step. Match the label to the owner's requested scope: creating a task can finish a request to create a task, but cannot finish a request to implement it. Distinguish task created/queued, handoff sent, execution confirmed, and result verified. 'Created a task; execution is unconfirmed' must never become 'it is being worked on' without current evidence of execution. A sent message, assignment or open terminal is not that evidence.
