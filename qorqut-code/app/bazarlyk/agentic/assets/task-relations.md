Coherent projects, repository work, clients and contracts are ordinary parent Tasks. Reuse an existing parent Task and give child Tasks its parent_id; link any other related Task, material or table with relationships_create (a Task may relate to several groups, and a parent is never inferred from a related link). Small standalone actions need no parent. A parent and its children are independent: completing or reopening a parent never changes a child, and children never change the parent. Read existing Tasks before creating one.
