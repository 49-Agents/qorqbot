# qorqutbot-ui

Independent frontend for qorqut-core. The [UI plan](docs/UI-PLAN.md) specifies agent navigation, persistent chat, inline browser intervention and the collapsible inspector.

See the [documentation index](docs/README.md) for the authoritative backend and browser plans. The backend runs headlessly; this repository owns no application coordination or configuration authority.

Implementation proceeds on isolated branches with independent review. No application has been deployed.
