# Security reporting

Report security vulnerabilities privately through
[GitHub private vulnerability reporting](https://github.com/49-Agents/qorqbot/security/advisories/new).
Do not open a public issue for a security vulnerability.

Do not include credentials, cookies, account exports, personal conversations,
private databases or private installation paths in public issues. For an ordinary
bug report, provide a minimal synthetic reproduction and the affected Qorqbot and
prerequisite versions.

Security reports should describe the affected version, prerequisite versions,
impact and minimal reproduction. Share exploit details and sensitive diagnostics
through the private reporting channel.

Only specifically qualified release versions are supported. Historical commits
and private development candidates do not imply support or security qualification.
External programs and provider accounts are maintained by their respective
vendors and users; Qorqbot's release notes document tested prerequisites.
