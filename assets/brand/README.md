# Qorqbot brand assets

The approved mark has a white round face, tilted black almond eyes, and a small
upward-curled mustache. It has no horns.

- `qorqbot-logo.svg` — editable master with a transparent background.
- `qorqbot-logo.png` — transparent 1024 × 1024 export.
- `qorqbot-logo-dark.png` — 1024 × 1024 export on charcoal, used by the README.

Use this folder for shared product, README and launch assets. Make future logo
changes in the SVG master, then regenerate the PNGs. Earlier concepts under
`docs/assets/` are drafts.
