Five independent ACLA workers used Opus at max effort with self-review disabled. Their films reuse the approved Qorqbot mascot, launch-slide artwork, context/provider marks, existing landing composition and licensed 49IDE fonts/GSAP. Each directory includes provenance, timing and license notices. These are authored product concepts; none is a live product acceptance recording or a final owner selection.

Each HTML entry is self-contained and exposes the playback interface specified in [PLAN.md](PLAN.md). [Gallery setup and verification](gallery/README.md) records the shared template, playback adaptation and checks.
