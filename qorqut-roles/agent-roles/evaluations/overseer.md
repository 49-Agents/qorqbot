# Overseer pilot rubric

Use a small, owner-selected mixed set of whole authorized episodes containing
instructions, edits and outcomes, including examples where no lasting rule is
warranted. This is a later quality trial, not a claim established by structural
or synthetic tests. Do not run a provider session or copy live material for this
rubric. Retain the selected source revisions, coverage and gaps privately under
the host's existing access controls. Identify important expected cases before
inspecting the output so misses remain visible.

Assess extraction and review separately. Record source/delta versions and the
owner's feedback using owner-only Signoffs; preserve the original response and
attribution. Feedback is retained for possible later training, not fed back into
automatic extraction or training now.

| Extraction | Inspect |
| --- | --- |
| Coverage | Whole episode and frontier, continuations, absent sources, edits and final results; no Overseer work or mirrored feedback admitted |
| Recall and restraint | Plausible useful instructions, corrections, mistakes, friction and successes captured; one-off or irrelevant material not promoted into unsupported rules |
| Evidence | Real supporting source, original author and event, before/after references, observation distinct from interpretation, and uncertainty explicit |
| Scope and origin | Explicit scope retained; inferred scope narrow; direct, preference, decision and inference distinguished; current implementation checked |
| Conflict | Standing rule and evidence linked to an immediate clarification Signoff before any replacement, while unrelated work proceeds |

| Review | Inspect |
| --- | --- |
| Grouping | Equivalent intended behavior and compatible scope grouped; distinct changes separated; raw and contrary evidence retained |
| Support | Original events and episodes counted honestly, copies and unknown independence distinguished; one source can be eligible |
| Decisions | Rejection persists absent explicit reopening; completed behavior can receive a new later delta; already-satisfied work does not duplicate implementation |
| Priorities | Useful choices selected by judgment without a fixed formula; at most five actionable revisions, concise reasons, full expandable evidence and a stable batch |

Record concrete unsupported proposals, wrong origins, overbroad scopes, duplicate
groups, missed useful changes and unhelpful priorities. A high proposal count is
not a success measure. Report the assessed sample, unavailable evidence and
unresolved owner setup choices; do not generalize this small trial into calibrated
quality claims.
