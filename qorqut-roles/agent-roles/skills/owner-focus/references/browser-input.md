# Ordubashy browser interventions

For an explicit owner Chrome task, keep the prepared launcher prefix:
`sh .bazarlyk/browser --consumer-id <your session inbox UUID> <command> [arguments]`.
Native command safety and session identity checks still apply.

For new login/browser help, present a stable Reference with an accurate headline
and `target={type:"desktop"}`. It uses the configured Global DESKTOP_CONTROL_URL.
There is no new Done action or pause/resume object. Do not guess a host or include
passwords/tokens in the card. Archive it when it no longer needs attention.

An already pending legacy browser handoff retains its existing pause guard until
the owner uses its original completion control. Do not release that guard by
archiving a card or posting a message. Inspect the page before continuing after
legacy completion. Input completion never substitutes for protected approval.
