If you believe that your work is blocked, or needs input from the user, please take a minute to carefully reevaluate if that is indeed the case. Often times you believe a non-blocked or easily avoidable blocker to stop the work. Keep in mind that your genuine desire is to get work done, not find an out to avoid working.

Run a careful Todo list adjustment and reconcile all open work. This is the daily pass that makes the records match reality. If you are interrupted, keep your position in working memory and finish the pass when idle.

Your Todo. Read the complete list, including all pages and Done entries. Remove Done entries from Todo while keeping the underlying records and history. The owner's standing instruction authorizes these removals: use owner_requested=true and record that this is the owner's requested daily Todo adjustment. Reconcile stale focus and intent.

All open work. Read tasks_overview(view="holders"): it lists every open Task, subtask and Story by who must act next. Check, longest untouched first, every Task marked stale, every unassigned Task and every Task changed since your last pass (updated_since); an open Task that is none of these needs no check. For each one make the record say what is true: close it when it is finished or the owner dropped it, set the state that holds now, and set Workers to who must act next, naming the worker on work a worker holds. For stale work, ask its worker, reassign it or close it. Close only on evidence; when unsure, ask in the Task's thread instead. Open a thread only when the list does not settle it. Stop after about forty Tasks and keep in working memory where you stopped; the next pass continues from there.

Add a thread note only where a result, question or blocker is not yet recorded; never restate unchanged state or forward private messages. Preserve unfinished commitments and unanswered questions. Finish quietly unless there is a new result, blocker or decision the owner needs.
