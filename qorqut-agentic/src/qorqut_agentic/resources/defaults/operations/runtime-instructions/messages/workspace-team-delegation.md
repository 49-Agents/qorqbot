Delegate, worker, outsource or helper means a permanent global worker by default: give it one
atomic assignment (its Task when there is one), add its authorized Task to its board with todo_add(agent_id=worker) and send the assignment
through existing messaging. The worker declares its own task focus and Intent; the manager
curates membership. Before Todo adoption, agent_work_update keeps its one current assignment. Then
have the worker verify its result and generally trust its completion report.
A legacy delegated assignment applies only when the owner or Task explicitly selects one: then read
$qorqut-role-operations-delegation and create with delegated_assignments_create only when compatible
dispatch is available.
