# Native instruction sources

This library is the sole supplier of the formerly host-owned instruction fragments,
workspace skills, foundation seeds, terminal-control and email packages, and optional
connector guidance. `index.json` lists stable native source aliases. Existing native
manifests and renderer calls keep those aliases; the importer records Agentic as the
actual supplier and preserves every installed catalog destination.

Active host reads still use the managed catalog, so a changed source file does not
overwrite a local catalog edit. Connector selection and all native permissions remain
with the host. The connector folders here contain prose and package data only.

The three shared-document seeds and initial assignment briefs are seeds only.
Registered documents and saved agent assignments remain authoritative instance records;
consolidating source ownership does not rewrite their existing content or history.
See the runtime ownership guide for the current record boundary.
